# News Explorer (Frontend)

Search the latest news with the News API, sign in (simulated), and save articles to your profile.

**Live site:** https://lunkant.github.io/news_explorer_frontend/

## Tech

React 18, Vite, React Router, CSS (BEM), News API

## Features

- Search news from the last 7 days, 3 results at a time with "Show more"
- Preloader, "Nothing found" and error states
- Sign up / sign in popups with validation (backend simulated)
- Save and delete articles; protected Saved articles page
- Responsive: desktop, tablet, phone (hamburger menu)
